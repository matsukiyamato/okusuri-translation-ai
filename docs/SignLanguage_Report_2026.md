# 2028年新卒人事（元エンジニア）視点から見る：日本手話の構造・教育・テクノロジーの最新動向（2026年版）

ご質問ありがとうございます。2028年新卒採用を見据える人事担当者（元エンジニア）の視点から、IT業界におけるダイバーシティ＆インクルージョン（D&I）やアクセシビリティの重要性を踏まえ、2026年時点の最新情報に基づき、推論や迎合を排した事実ベースで回答いたします。

## 1. 手話と日本語の決定的な違いについて

手話と日本語は、単なる「表現方法の違い」ではなく、**言語学的に全く異なる独立した言語体系**を持っています。

日本で主に使用されている手話には、大きく分けて「日本手話（JSL: Japanese Sign Language）」と「日本語対応手話（Signed Japanese）」の2種類が存在します[1][2]。

| 特徴 | 日本手話（JSL） | 日本語対応手話（手指日本語） |
| :--- | :--- | :--- |
| **言語体系** | 日本語とは異なる独自の文法・語彙を持つ独立した言語 | 日本語の文法・語順に手話単語を当てはめた表現方法 |
| **語順** | 目的語・主語・動詞など柔軟。疑問詞は文末に置かれることが多い | 日本語の語順（主語→目的語→動詞）と完全に一致 |
| **表現要素** | 手の動きだけでなく、眉の動き、視線、口形、うなずきなどの非手指動作（NMM）が文法的な意味を持つ | 主に手の動きと日本語の口形（口パク）を使用する |
| **主な使用者** | ろう両親を持つろう児や、幼少期からろうコミュニティで育ったろう者（第一言語） | 中途失聴者、難聴者、日本語を第一言語として習得した後に手話を学んだ人 |

日本手話は、音声言語である日本語を「手で表現したもの」ではありません。英語と日本語が違う言語であるように、日本手話と日本語は根本的に異なる言語です。例えば、日本語の「ドアを開ける」という表現に対し、日本手話では「どのようなドアを」「どのように開けるか」によって身体動作を細かく区別します[3]。

## 2. 手話使用者は「あいうえお」の形で手話を行っているのか

結論から申し上げますと、**日常的な日本手話の会話において「あいうえお」のような一文字ずつの表現（指文字）を主体として会話することはありません**。

「あいうえお」の五十音に対応する手の形は「指文字」と呼ばれます。指文字は、固有名詞（人名、地名）、外来語、あるいは手話単語が存在しない新しい専門用語などを表現する際の**補助的な手段**として使用されます[4]。

日本手話は、一つの動作（単語）で一つの概念や意味を表します。例えば「りんご」という単語は、指文字で「り・ん・ご」と表すのではなく、「りんご」を意味する一つの手話動作で表現されます。指文字だけで会話をすることは、音声言語で例えるなら、すべての会話をアルファベットのスペルアウト（A-P-P-L-E）で行うようなものであり、非常に非効率です。

## 3. 聴覚障害児の学校（ろう学校）における教育の現状

日本のろう学校（聴覚特別支援学校）における教育方針は、歴史的に変遷を経ており、2026年現在も過渡期にあります。

かつてのろう教育では、相手の口の動きを読み取り、自らも発声する「口話法」が推進され、手話の使用が禁止されていた時代がありました[5]。しかし現在では、手話の重要性が再認識されています。

現在のろう学校の現状は以下の通りです：

* **教員の手話スキル不足**：文部科学省の指針等で手話の活用が推奨されているものの、ろう学校の教員全員が日本手話を流暢に使いこなせるわけではありません。多くの教員は聴者であり、教員養成課程で日本手話を十分に習得する機会が不足しているという構造的な課題があります[6]。
* **指導方法の混在**：授業では、教員によって「日本語対応手話」が使われたり、音声と手話を併用したりするケースが多く、純粋な「日本手話」のみで教育を受けられる環境（バイリンガルろう教育）は、一部の私立ろう学校や特定のクラスに限られています[7]。
* **自然習得の場としての機能**：多くのろう児は、教員からではなく、ろうの先輩や同級生との交流を通じて、自然に日本手話を習得しています[8]。

## 4. 医療用語や薬の説明に関する手話の習得状況

手話使用者が医療用語や薬に関する手話を、学校教育や成長過程で体系的に習得する機会は**極めて限定的**です。

* **学校教育での限界**：ろう学校のカリキュラムにおいて、高度な医療用語や薬効に関する専門的な手話を学ぶ時間は設けられていません。一般的な健康・衛生に関する基礎語彙にとどまります。
* **医療手話の特殊性**：医療用語の手話は、一般的な手話奉仕員や手話通訳者の養成カリキュラムでも深く扱われないことが多く、専門的な学習会等も不足しています[9]。
* **新しい用語への対応**：新薬や新しい医療概念（例：新型コロナウイルス関連用語など）が登場した際、標準的な手話単語が定着するまでに時間がかかります。

## 5. 薬の説明に対する手話使用者の理解度と課題

薬局や医療機関における薬の説明において、手話使用者（特に日本手話を第一言語とするろう者）は深刻な情報格差に直面しています。

* **書面（日本語）への依存と限界**：薬剤師は筆談や「お薬の説明書（薬剤情報提供書）」を用いて説明することが一般的です。しかし、前述の通り日本手話と日本語は異なる言語であるため、日本手話を第一言語とする高齢のろう者などの中には、日本語の長文や専門的な医療用語（例：「食間」「頓服」「副作用」など）の読解に困難を感じる方が少なくありません[10]。
* **手話通訳の専門性不足**：医療現場に手話通訳者が同行した場合でも、通訳者自身が医療・薬学の専門知識を持っていない場合、正確なニュアンス（薬の飲み方、副作用の兆候など）が伝わらないリスク（ヒヤリ・ハット事例）が報告されています[11]。
* **薬剤師側の手話スキル**：手話ができる薬剤師（ろう薬剤師含む）は全国的に非常に少なく、多くの薬局では身振り手振りや筆談に頼らざるを得ないのが現状です。

## 6. 手話対象者向けのアプリ・Webサービスの最新動向（2026年）

2026年現在、AI技術の進化により、手話と音声を双方向に翻訳する「デフテック（Deaf-Tech）」領域のスタートアップやサービスが実用化フェーズに入っています。

### 代表的なサービス：SureTalk（ソフトバンク）
ソフトバンクが電気通信大学等と共同開発したAI手話翻訳アプリです[12]。
* **機能**：スマートフォンのカメラで手話の骨格動作をAIが認識し、リアルタイムでテキストに変換。逆に音声ユーザーの言葉もテキスト化し、チャット形式で対話が可能です。
* **特徴**：画像そのものではなく「骨格の動き」を抽出してAIに学習させています。ユーザー自身が手話動画を登録し、AIを育成していく「参加型」の仕組みを持っています。
* **現状と課題**：2026年現在、複数の自治体の窓口等で実証実験・導入が進んでいます。しかし、手話は個人差（方言や癖）が大きく、三次元の動きを二次元カメラで正確に捉える技術的ハードルがあるため、複雑な医療相談や契約などの高度な通訳を完全に代替するレベルには至っておらず、窓口での一次対応などの補助的ツールとして位置づけられています[13]。

### 遠隔手話通訳サービス（みえる通訳、手話リンクなど）
* **機能**：タブレットやスマートフォンを通じて、コールセンターにいるプロの手話通訳者をビデオ通話で呼び出し、リアルタイムで通訳を行うサービスです。
* **現状**：AI翻訳の精度が発展途上である現在、確実な意思疎通手段として、自治体の窓口、携帯電話ショップ、一部の医療機関などで導入が拡大しています[14]。

### 2028年新卒人事（元エンジニア）としての視点

2024年4月の改正障害者差別解消法施行により、民間企業における「合理的配慮の提供」が法的義務となりました[15]。2028年卒の学生（特にITエンジニア志望層）は、企業の技術力だけでなく、ダイバーシティやインクルージョンへの取り組み、アクセシビリティを考慮したプロダクト開発（インクルーシブデザイン）の姿勢を企業選びの重要な指標としています。

聴覚障害者の雇用やサービス提供において、「筆談すれば済む」「日本語のテキストを読ませればよい」という認識は、日本手話と日本語の言語的差異を理解していない証左とみなされます。AI手話翻訳（SureTalk等）のAPI連携や、遠隔手話通訳のUI/UX統合など、テクノロジーを用いて言語の壁（情報保障の課題）を解決する姿勢を示すことが、優秀なエンジニア層を惹きつける採用ブランディングにおいても極めて重要になると分析します。
