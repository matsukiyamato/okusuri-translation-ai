## 1.2 関数仕様 

**① encrypt_email(email: str) -> bytes**

**処理概要**：ユーザーのメールアドレスをAES-256-GCMで暗号化する。

**ロジック**：
 1. AES_KEY_HEX をバイト配列にデコード。
 2. 12バイトの暗号化nonce（乱数）を生成。
 3. AESGCMクラスを用いて email.encode('utf-8') を暗号化。
 4. nonce + cipher_text の結合バイナリデータを返却（MySQLの VARBINARY 型へ直接格納）。

**② decrypt_email(encrypted_data: bytes) -> str**

**処理概要**：暗号化されたバイナリを復号する・

**ロジック**：
 1. encrypted_data から先頭12バイトを nonce、残りを cipher_text として分離。
 2. 復号し、utf-8 文字列として返却。

**③ hash_password(password: str) -> str**

 **処理概要**：パスワードをArgon2idアルゴリズムでハッシュ化する。
 
 **ロジック**：
 ph.hash(password) を実行して生成された文字列を返却。

**④ verify_password(hashed: str, password: str) -> bool**

 **処理概要**：入力パスワードの照合。

 **ロジック**：
 ph.verify(hashed, password) を実行。一致すれば True、VerifyMismatchError 発生時は False を返す。

**⑤ generate_setup_token(email_hash: str) -> str**

 **処理概要**：有効期限10分の仮登録用JWTを発行する。

 **ロジック**：

 　**クレーム構造**：JSON
 ```JSON
{
    "iss": "okusuri-translation-ai-backend",
    "sub": "tmp_registration_session",
    "exp": "現在時刻 + 10分",
    "scope": "user:complete_registration",
    "h_mail": "email_hash"
}   
 ```

 - SETUP_JWT_SECRET を用いてHS256署名。内部システムID（UUID）は一切含めない。

**⑥ generate_session_token(interface_mode: Optional[str]) -> str**

 **処理概要**：有効期限24時間の正規セッションJWTを発行。
 
 **ロジック**：

 　**クレーム構造**：JSON
```JSON
{
  "iss": "okusuri-translation-ai-backend",
  "sub": "authenticated_session",
  "exp": "現在時刻 + 24時間",
  "scope": "user:standard_access",
  "usr_mode": interface_mode
}
```

### 3. バックエンドAPI詳細設計 (backend/app/api/)

## 3.1 認証・認可 API (backend/app/api/auth.py)

**① Google OAuth コールバック (/api/v1/auth/google/callback [GET])**

 **入力**：Google認証プロバイダからリダイレクトされる

 **ロジック**：
 1. 認可コードを用いてGoogle APIから google_sub と email を取得。
 2. DBの users テーブルを google_sub で検索。
 3. **分岐A (新規ユーザー)**:
　・email を encrypt_email() で暗号化。
　・id = UUIDv4, google_sub, encrypted_email, password_hash = NULL, interface_mode = NULL でレコードをINSERT。
　・generate_setup_token() を実行して仮登録用トークンを発行。
　・200 OK とともに、セットアップトークンと is_new_user = true を返却。
 4. **分岐B (既存ユーザーかつ password_hash が NULL の場合)**:
　・何らかの理由でパスワード設定を離脱したユーザー。generate_setup_token() を再発行して200 OK返却。
 5. **分岐C (既存ユーザーかつ本登録完了済み)**:
　・200 OK とともに、正規セッションJWT（generate_session_token()）と is_new_user = false を返却。

**② パスワード追加設定 (/api/v1/auth/register/setup-password [POST])**

 **ヘッダー**：Authorization: Bearer <SETUP_JWT_TOKEN>
 **ボディ**：
```JSON
{
  "password": "ユーザーが入力した平文パスワード"
}
```
 **ロジック**：
 1. SETUP_JWT_SECRET でトークンを検証。有効期限切れ、またはスコープ不正（scope != 'user:complete_registration'）の場合は 401 Unauthorized。
 2. トークン内の h_mail 等から対象ユーザーレコードを特定。
 3. **ガードレールロジック**: 該当レコードの password_hash がすでに NOT NULL である場合は、「二重登録防止」として 400 Bad Request で即時拒否。
 4. 入力された password を hash_password() で Argon2id ハッシュ化。
 5. DBの該当レコードを UPDATE users SET password_hash = :hash, updated_at = NOW() WHERE id = :id で更新。
 6. 200 OK を返却（フロントエンド側はこれを受けてログイン画面へ明示的リダイレクト）。

**③ ローカル認証ログイン (/api/v1/auth/login [POST])**

 **ボディ**：
```JSON
{
  "email": "平文メールアドレス",
  "password": "平文パスワード"
}
```
 **ロジック**：
 1. 入力された email を encrypt_email() で暗号化。
 2. 暗号化されたバイナリ値をキーに、DBからレコードをセレクト。
 3. **安全ガードレールロジック**: レコードが存在しても、password_hash IS NULL（**仮登録ステート**）**のユーザーであった場合は、パスワード検証を行わずに即時 401 Unauthorized で認証を完全遮断・拒否する。**
 4. verify_password() でハッシュ値を照合。不一致なら 401 Unauthorized。
 5. 認証成功時、generate_session_token(interface_mode) を発行して返却。  
 
## 3.2 OCR・構造化・RAG処理 API (backend/app/api/ocr.py, rag.py)

**① 薬剤説明書解析 (/api/v1/ocr/analyze [POST])**

 4. response_mime_type="application/json" を指定し、以下のPydanticスキーマ構造へマッピング（JSON Mode強制、ハルシネーション・構造崩れ防止）。

 5. フロントエンドへJSON構造化データを返却。

 **ヘッダー**：Authorization: Bearer <JWT_TOKEN>

 **ボディ:上記の OcrStructuredData**

 1. FastMCP クライアントを非同期起動。**PMDAの外部公的データベース**（**患者向医薬品ガイド MCP**）へリアルタイムに接続要求を発行し、medicine_name を引数に**公式添付情報**を取得。

### 4. API従量課金超過に伴う自動システム停止ミドルウェア(backend/app/middleware/rate_limiter.py)

ポートフォリオを無料枠内で安全に公開・運用し、破産的課金を自動で防止するサーキットブレーカー。

```Python 
from fastapi import Request, HTTPException
from fastapi.responses import JSONResponse
import starlette.status as status

# インメモリまたはRedisでリクエスト累積を管理（2026年運用想定値）
MONTHLY_API_COUNTER = 0
# 無料枠枠を保護するための閾値（例: 月間最大リクエスト上限）
MAX_FREE_LIMIT = 4000 

async def api_budget_protection_middleware(request: Request, call_next):
    global MONTHLY_API_COUNTER
    
    # 有料APIに直結するエンドポイントを監視対象とする
    monitored_paths = ["/api/v1/ocr/analyze", "/api/v1/rag/translate", "/api/v1/voice/query"]
    
    if request.url.path in monitored_paths:
        if MONTHLY_API_COUNTER >= MAX_FREE_LIMIT:
            # 外部有料APIへのアウトバウンドを物理的に遮断し、503を即時返却
            return JSONResponse(
                status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
                content={
                    "error": "Service Temporarily Suspended",
                    "message": "API利用枠制限（無料枠保護）によるシステム自動一時停止中です。開発者へご連絡ください。"
                }
            )
        MONTHLY_API_COUNTER += 1
        
    response = await call_next(request)
    return response
```

### 5. データライフサイクル管理（ゴミデータ自動消去タスク：backend/services/auth_lifecycle.py）
不完全な仮登録データの無限増殖を防ぎ、DB容量とセキュリティクレンリネスを維持するバッチスクリプト。

```Python
import mysql.connector
from datetime import datetime, timedelta, timezone

def delete_expired_incomplete_users():
    """
    created_at から24時間以上経過し、かつ password_hash が NULL（仮登録ステート）のまま
    本登録が完了していないゴミレコードを、毎日自動で一括物理削除する。
    """
    # 2026年現在の安全なコネクション接続
    conn = mysql.connector.connect(
        host=os.environ["DB_HOST"],
        user=os.environ["DB_USER"],
        password=os.environ["DB_PASSWORD"],
        database=os.environ["DB_NAME"]
    )
    cursor = conn.cursor()
    
    # 24時間前の境界時刻を計算
    boundary_time = datetime.now(timezone.utc) - timedelta(hours=24)
    
    # 物理削除クエリ実行
    delete_query = """
        DELETE FROM users 
        WHERE password_hash IS NULL 
        AND created_at < %s
    """
    
    cursor.execute(delete_query, (boundary_time.strftime('%Y-%m-%d %H:%M:%S'),))
    conn.commit()
    
    cursor.close()
    conn.close()
```
